# Etiquette

Étiquettes courtes (durée, statut, niveau).

## Règles
- Un à trois mots. Neutre par défaut ; jaune pour signaler une nouveauté ; marine pour un repère fort.
- À utiliser avec parcimonie : pas dans les bandeaux de section.

## Code à copier
